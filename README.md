# Portfolio V3 — Florencia Giusti

Versión corregida con foto real, contenido enfocado en desarrollo web, proyectos preparados para enlazar demos reales y stack técnico actualizado.

## Abrir
```bash
npm install
npm run dev
```

Luego abrí http://localhost:3000

## Editar
- `components/Hero.js` — portada
- `components/About.js` — foto, perfil y formación
- `components/Projects.js` — presentación de proyectos
- `data/portfolio.js` — proyectos, servicios y tecnologías
- `components/Services.js` — servicios y stack
- `components/Contact.js` — contacto
